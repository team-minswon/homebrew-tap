# HeyMoa Homebrew tap

HeyMoa 데스크톱 앱의 공식 Homebrew tap입니다.

## 현재 배포 상태

첫 공개 베타 설치 파일을 준비하고 있습니다. 아직 공개 Release와 설치 가능한 `Casks/heymoa.rb`는 없습니다. 설치 파일의 실행·로그인·회의 녹음·중지 검증 후 실제 다운로드 URL과 SHA-256을 확인하여 cask를 게시합니다.

macOS 14.2 이상 Apple Silicon·Intel을 대상으로 준비하며, Windows 설치 파일은 Homebrew와 별도로 제공합니다. 지원 목표와 실제 검증 결과는 Release 본문에 구분해 기록합니다.

## 설치 및 업데이트

설치 가능한 cask가 게시되면 이 문서에 설치·업데이트 명령을 안내합니다. 공개 파일 없이 임시 URL이나 `sha256 :no_check`를 사용하는 cask를 제공하지 않습니다.

초기 베타는 Developer ID 서명·공증이 없는 파일일 수 있습니다. 해당 상태를 Release에 명시하며, Homebrew 설치가 macOS 출처 확인이나 마이크·시스템 소리 권한을 대신하지 않습니다. Gatekeeper 비활성화와 자동 quarantine 제거는 제공하지 않습니다.
