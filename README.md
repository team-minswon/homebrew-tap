# HeyMoa Homebrew tap

HeyMoa 데스크톱 앱의 공식 Homebrew tap입니다. macOS 14.2 이상, Apple Silicon을 지원합니다.

```sh
brew install --cask team-minswon/tap/heymoa
brew upgrade --cask heymoa
```

업데이트 전에 녹음과 오디오 전송이 끝났는지 확인해 주세요. Mac 앱은 Apple 서명·공증을 받았습니다.

0.1.4부터 앱의 설정 → 앱 업데이트에서도 새 버전을 확인할 수 있습니다. 0.1.5부터 신규 설치·미설정은 자동 업데이트가 기본 켜짐이며, 직접 끈 선택은 유지합니다. 새 버전을 자동 다운로드하고 녹음·오디오 전송이 끝난 뒤 앱을 정상 종료할 때 적용합니다. 자동 업데이트를 끈 경우에도 새 버전을 안내하고, 다운로드와 적용은 직접 선택할 수 있습니다.

메뉴 막대 팝업의 설정 버튼이나 우클릭 메뉴의 설정에서 불투명도와 업데이트를 조절합니다.
