# HeyMoa Homebrew tap

HeyMoa 데스크톱 앱의 공식 Homebrew tap입니다. macOS 14.2 이상, Apple Silicon·Intel을 지원합니다.

```sh
brew install --cask team-minswon/tap/heymoa
brew upgrade --cask heymoa
```

업데이트 전에 녹음을 중지해 주세요. 현재 베타는 서명·공증이 적용되지 않아 macOS의 앱 실행 승인이 필요할 수 있습니다.
