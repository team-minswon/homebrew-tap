# HeyMoa Homebrew tap

HeyMoa 데스크톱 앱의 공식 Homebrew tap입니다. macOS 14.2 이상, Apple Silicon을 지원합니다.

```sh
brew install --cask team-minswon/tap/heymoa
brew upgrade --cask heymoa
```

업데이트 전에 녹음을 중지해 주세요. Mac 앱은 Apple 서명·공증을 받았습니다.

0.1.4부터 앱의 설정 → 앱 업데이트에서도 새 버전을 확인할 수 있습니다. 자동 업데이트는 기본으로 꺼져 있으며, 켜면 새 버전을 자동 다운로드하고 녹음·오디오 전송이 끝난 뒤 앱을 정상 종료할 때 적용합니다.
